# Práctica 4: Entrenamiento de una red neuronal

Para repetir las pruebas de la red de 4 salidas, abre una terminal en
la carpeta que contiene `fc.py` y ejecuta:

```bash
python3 evaluar_binario.py
```

El script entrena 11 configuraciones y evalúa 100 imágenes por
configuración (10 por dígito). Muestra el tiempo de entrenamiento y
el porcentaje de aciertos, y guarda un CSV en la carpeta personal.
